# Checklist de Revisão de Código

- [ ] O código faz o que a descrição da tarefa/PR promete?
- [ ] Nomes de variáveis, funções e arquivos são claros e fazem sentido?
- [ ] Existe tratamento de erros/exceções nos pontos críticos?
- [ ] Há duplicação de código que poderia ser evitada?
- [ ] O código tem (ou quebra) algum teste existente?
- [ ] Alguma informação sensível (senha, token, chave) está exposta no código?
